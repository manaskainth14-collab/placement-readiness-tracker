# Placement Readiness Tracker

A command-line tool that records students' practice-test scores (aptitude,
verbal, coding), calculates averages and grades, finds the top scorer and
flags students who need extra practice.

## How to run
```bash
python placement_tracker.py
```
Enter the new student's name, roll number and three scores (0-100) when asked.

For the runner-up problem:
```bash
python runner_up.py
```
